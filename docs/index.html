¿Cómo instalar?

Copias, pegas y listo. Funciona en Claude Code, en la terminal, la app de escritorio o la web.

  1. Pica "Instalar skill"

    La skill se copia sola.

  2. Pégala en Claude Code y dale Enter

    Claude la instala por ti. No tienes que tocar ninguna carpeta.

  3. Úsala hablando normal

    Por ejemplo: "pásalo por la Tijera" o "dame cien malas ideas para una marca de café".

  4. ¿Las quieres todas?

    Cópialas todas de una vez y pégalas igual.
